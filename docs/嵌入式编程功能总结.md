# Frok Code 嵌入式编程功能总结

**日期：** 2026-05-11
**作者：** 聪音

## 概述

为 Frok Code 添加了完整的嵌入式编程能力，支持 Arduino、ESP32、STM32 三个平台的代码生成、编译、烧录和串口监视。采用完全自动化设计，用户只需自然语言输入，系统自动检测设备并完成整个开发流程。

## 架构设计

```
frok/
├── embedded.py              # 基类 + 工具 + 自动检测
├── platforms/
│   ├── __init__.py          # 平台自动发现
│   ├── arduino.py           # Arduino 适配器
│   ├── esp32.py             # ESP32 适配器
│   └── stm32.py             # STM32 适配器
└── skills/
    └── embedded.json        # 嵌入式编程技能
```

### 核心接口

```python
class EmbeddedPlatform(ABC):
    """嵌入式平台基类"""

    @property
    def name(self) -> str: ...           # 平台名称
    @property
    def display_name(self) -> str: ...   # 显示名称
    @property
    def toolchain_cmd(self) -> str: ...  # 工具链命令

    def detect(self) -> bool: ...        # 检测工具链
    def generate_code(self, spec: dict) -> str: ...  # 生成代码
    def compile(self, sketch_path: str, board: str = None) -> CompileResult: ...  # 编译
    def upload(self, sketch_path: str, port: str = None, board: str = None) -> UploadResult: ...  # 烧录
    def list_boards(self) -> list: ...   # 列出开发板
    def list_ports(self) -> list: ...    # 列出串口
```

## 平台支持

### Arduino

- **工具链：** arduino-cli
- **代码模板：** blink、sensor、default
- **支持开发板：** Uno、Mega、Nano、Leonardo 等

### ESP32

- **工具链：** ESP-IDF 或 arduino-cli
- **代码模板：** wifi、mqtt、sensor、ble、default
- **支持开发板：** ESP32、ESP32-S2、ESP32-S3、ESP32-C3 等

### STM32

- **工具链：** arm-none-eabi-gcc + st-flash/openocd
- **代码模板：** gpio、uart、default
- **支持开发板：** Blue Pill、Black Pill、Discovery、Nucleo 等

## 自动检测策略

### 设备检测流程

1. 扫描所有串口设备
2. 通过 USB VID/PID 推断平台
3. 智能选择：单设备自动选择，多设备询问用户

### 平台推断规则

| VID:PID       | 推断结果                  |
| ------------- | --------------------- |
| 0x2341:*      | Arduino 官方板           |
| 0x1A86:0x7523 | CH340 串口（Arduino 兼容板） |
| 0x10C4:0xEA60 | CP2102 串口（ESP32 常见）   |
| 0x0483:0x374B | ST-Link V2（STM32）     |

## 工作流示例

### 示例 1：Arduino LED 闪烁

```
用户: 帮我写个 LED 闪烁

Frok:
1. [代码生成] 生成 Arduino LED Blink
2. [自动检测] 扫描串口 → 发现 COM5 (Arduino Uno)
3. [自动编译] arduino-cli compile
4. [自动烧录] 烧录到 COM5
5. [自动监视] 串口输出 "LED ON/OFF"
```

### 示例 2：ESP32 温湿度监测

```
用户: 帮我做一个 ESP32 的温湿度监测，DHT22 接 GPIO4，数据发到 MQTT

Frok:
1. [代码生成] 生成 ESP32 + DHT22 + MQTT 代码
2. [自动检测] 扫描串口 → 发现 COM3 (CH340, 推断 ESP32)
3. [自动编译] 调用 idf.py 编译
4. [自动烧录] 烧录到 COM3
5. [自动监视] 打开串口 115200，实时显示温湿度数据
```

### 示例 3：STM32 按键中断

```
用户: STM32 按键中断控制 LED

Frok:
1. [代码生成] 生成 STM32 HAL 库按键中断代码
2. [自动检测] 扫描调试器 → 发现 ST-Link
3. [自动编译] arm-none-eabi-gcc 编译
4. [自动烧录] st-flash 烧录
5. [完成] 提示用户按下按键测试
```
